Scorecard：开源项目成熟度质检 / Open-source project maturity audit

检查什么

粘一个 GitHub 仓库、npm 包、网页 URL 或 GitHub 用户名，按各自的客观判据获得维度评分与整改清单。品牌 GEO 使用独立的可见性判据。

Audit a GitHub repository or profile, npm package or website against evidence-based criteria. Brand GEO uses its own visibility criteria.

如何解读报告

读不到的项标「无法核实」而非 0 分；报告列出证据、缺口与需要人工核实的内容。不同类型的判据互不通用。

使用与项目资料

网页免登录；也可查看开源代码及项目质检技能说明。
